# 个人作品集网站

> 一个手写的、零依赖的个人作品集。中英双语，深色主题，滚动动画，移动端适配，
> 自带访问统计与留言板。

五个区块：**首页 / 关于我 / 项目 / 留言板 / 联系方式**。点右上角（宽屏是左下角）的
语言开关即可中英一键切换。没有构建步骤，没有 `npm install`，没有框架，
没有 CDN 依赖。

```bash
cd portfolio
node server.js          # → http://localhost:5200/
```

启动后会打印一段自检结果（含 `本机自检 通过`），**这个终端窗口要保持开着** ——
它是服务进程本身，关掉窗口或按 `Ctrl+C` 服务就停了（正常停止会打印"已停止"，退出码 0）。
想一边逛页面一边敲命令，再开一个终端就行。

**统计与留言需要这个 Node 服务**（数据得有个地方存）。想只要一个纯静态站点的话，
直接开 `index.html` 或把它丢到任何静态托管上：页面照常工作，
**访问统计与留言板会自己收起来**，不会显示假数据，也不会留下点了没反应的按钮。

`file://` 下唯一另外的区别：剪贴板 API（"复制邮箱"）会被浏览器拒绝，
那时按钮退回到 `document.execCommand('copy')`。

## 0. 三个功能（这一版新增）

### 中英双语

按钮上写的是"**切过去之后是什么语言**"，所以中文界面显示 `English`。
选择记在 `localStorage`，刷新后还在；URL 上会同步 `?lang=en`，方便直接分享某个语言版本的链接。
首帧就把语言定下来（内联脚本），英文用户不会闪一下中文。
文案集中在 `main.js` 顶部的 `I18N` 里，中英各一份，**测试会校验每个 `data-i18n` 键两边都存在**。

### 访问统计

`POST /api/visit` 记一次访问，服务端按天聚合 PV；UV 用「本机随机 ID → HMAC 哈希」去重，
**不存原始 IP**。页脚显示总访问 / 今日 / 访客数，加一条近 14 天的折线。
数据全是真的：拿不到后端就整块隐藏，绝不编数字。

### 留言板

访客留称呼 + 一句话，服务端落盘。带蜜罐字段、同一地址 60 秒冷却、每天 8 条上限、
长度与内容校验（纯灌水/一堆链接会被拒）。留言按时间倒序分页展示，
称呼会自动取首字母做头像。审核/删除见第 6 节。

## 1. 它长什么样，以及为什么

深色主题容易做成两种样子：一种是纯黑底加一个荧光绿/朱红强调色，一种是毛玻璃卡片满天飞。
这个站都没有走。它的母题是**暗室里正在扫描成像的工作台**——
底色是带蓝调的炭黑（不是纯黑，纯黑在 LCD 上会把阴影压死），
格线是极淡的点阵网格，像绘图纸。

| | | |
| --- | --- | --- |
| **画布** | `#0b1015` 炭黑蓝 | 有底纹：一层 28px 的点阵网格 + 右上角一盏冷光 |
| **层次** | `#141c24` / `#1a2530` | 卡片和侧栏的浮起面 |
| **主强调** | `#4fd1c5` 青绿 | 暗房指示灯的色，用在链接、进度、扫描线、刻线上 |
| **辅强调** | `#e6a758` 琥珀 | 只出现在"计划时刻""进行中"这类状态上 |
| **正文墨色** | `#e9eef3` / `#a2b0bd` / `#71818f` | 三级灰阶，正文对比度 16.4:1 |

**字体**是两套搭配：拉丁文用 **Sora**（几何感强、字重差异大，标题压到 -0.035em 字距），
正文用 **Inter**；中文回落到系统字体（苹方 / 微软雅黑），
**不加载中文字体文件**——中文字体动辄几 MB，为了"好看"让首屏等两秒不划算。
标签、编号、时间用得等宽字体，因为它们本来就是数据，不是文案。

Web 字体是**增强项**：`fonts.googleapis.com` 拿不到时会静默认回落到系统字体栈，
布局和排版层级都不会塌（`display=swap` + 完整的 `var(--font-*)` 回落链）。

### 签名元素：扫描成像的头像

整个页面唯一"表演"了一下的是首屏头像。它不是为了炫技——
`assets/avatar.jpg` 是一张实拍照片，配一条自上而下扫过的扫描线，
加上一行 `initializing profile → profile · ready` 的状态字。

过程是：**先看到背景的光斑，然后一条青绿的扫描线从顶上扫下来，把肖像"显影"出来。**
扫描线只播一次，播完就退场（状态字淡到 0.32 保持"已就绪"的暗示）。

换成自己的照片照样成立——照片被扫描线显影反而更有说服力：头像下面就有
**「上传照片」**按钮，传一次存在本机浏览器里，刷新后还在。见 [`assets/README.md`](assets/README.md)。

### 只在必要时动

除了头像那一段，其余动效都很短：

| 动效 | 时长 | 说明 |
| --- | --- | --- |
| 滚动揭示 | 0.68s | 元素进入视口时上移 18px 淡入，卡片按左右两列错开 90ms |
| 悬停 | 0.34s | 卡片抬起 4px、边框转青绿、缩略图轻微推近 |
| 联系方式的横线 | 0.45s | 鼠标扫过时一条青绿线从左铺满 |
| 进度条 | 0.12s | 左侧索引栏的滚动进度，跟手 |

**`prefers-reduced-motion: reduce` 时全部关掉**——扫描线直接不渲染，
揭示动画变成直接显示。这不是可选项，前庭敏感的人会因为这个头疼。

### 移动端

| 宽度 | 版式 |
| --- | --- |
| ≥ 1180px | 左侧 92px 固定索引栏（竖向标签 + 滚动进度），正文 1180px 居中 |
| 760–1179px | 索引栏收起，顶部吸附栏 ← 横向导航 + 主题开关 |
| < 760px | 项目卡片单列；技能从两栏变上下；头像 `min(100%, 400px)` 自适应收缩 |

标题字号用 `clamp(2.75rem, 12.5vw, 6.6rem)`，
**下限按中文定**——"薛小飞"三个字比同字号的拉丁字母占宽得多，
按 `12.5vw` 一路缩放，在 320px 上会折成两行。实测 320 / 390 / 834 / 1440 四档都保持单行。

### 顺带做了的两件事

- **浅色主题不是摆设。** 主题开关默认跟随系统，用户点过就记住（`localStorage`
  + 首帧内联脚本，浅色用户不会看到一下黑闪）。浅色不是把颜色取反，
  而是换成纸面 + 墨色的另一套令牌。
- **左栏的索引数字是真的读数。** `01%` 到 `100%` 是滚动进度，不是装饰性的编号。
  章节标题上的 `02 / 03 / 04` 同理——它们是顺序标题，
  01 是首页本身，所以关于我从 02 开始。

## 3. 怎么改成你自己的

**基本上只用动 `main.js` 顶部的 `site` 对象**：

```js
var site = {
  owner: '薛小飞',
  email: 'xuexiaofei666@proton.me',
  github: 'https://github.com/BlueQBL',   // "查看全部项目"按钮指向这里
  links:    [ /* 联系方式：kindKey / label / noteKey / href 或 copy */ ],
  projects: [ /* 项目：name / sub / desc / cap 支持中英双语，见下 */ ]
};
```

- **改文案 / 加语言**：所有界面文案在 `main.js` 顶部的 `I18N` 里，`zh` 与 `en` 各一份，
  键名与 `index.html` 上的 `data-i18n` 对应。加第三种语言就是再加一个键组 +
  在 `applyLang` 的按钮逻辑里放行。**`smoke-test.js` 会检查每个 `data-i18n` 键在中英两边都存在**，
  漏了就报错。
- **项目描述的中英双语**：项目里的文本字段用 `L('中文','English')` 包一层，
  渲染时按当前语言取值（这样切换语言时卡片会跟着变，而不是只在加载时定一次）。
- **换联系方式**：改 `links`。带 `href` 的渲染成外链（自动 `target="_blank"` +
  `rel="noopener noreferrer"`），带 `copy` 的渲染成可复制项；**想删哪条就直接删掉整项**，
  布局不会塌（现在是邮件 / GitHub / 微信三条）。
- **加项目**：往 `projects` 数组里**追加一项就行**，别的地方都不用动 ——
  卡片、"N 个项目"的计数、底部的"在 GitHub 上查看全部项目"入口都会自动跟上。
  每项必填 `name` / `desc` / `stack` / `href`，其余可省。
  `art` 指向 `main.js` 里某个画缩略图的函数，写新的就照抄 `artLedger` 的结构（纯 SVG 字符串）。
  项目多了以后：把 `site.projects` 拆成 `projects.js`（`window.__PROJECTS = [...]`），
  在 `main.js` 之前引入即可，其余逻辑零改动。
- **换真实截图**：把图丢进 `assets/shots/`，命名对上 `shot` 字段即可，**代码不用改**。
  **现在是空的，这是故意的**——仓库里没有真实截图，所以 6 张缩略图全部由
  `main.js` 按各项目的视觉母题手绘（流水账是热敏小票、水尺是刻度柱、
  狼人杀是牌桌…），而不是塞 6 张灰色占位图或者外链别的站点的图片。
  图片加载失败时 `onerror` 自动回落到 SVG，放一半也不会开天窗。
- **换头像**：网页上直接点「上传照片」就行（见下一节），不用改代码；
  想换掉默认那张，替换 `assets/avatar.jpg`，或改 `index.html` 里那一个 `src`
  （记得同时改 `main.js` 里的 `DEFAULT_PHOTO` 和 `onerror` 兜底路径）。
- **改配色**：只动 `styles.css` 顶部 `:root` 和 `[data-theme="light"]` 两组令牌，
  整站跟着变，两套主题各改各的。

### 头像上传是怎么工作的

首屏头像下面有一个 **「上传照片」** 按钮（传过之后旁边会出现「恢复默认」）：

1. 选一张本地图片（jpg / png / webp / heic 视浏览器支持）；
2. 在浏览器里用 `canvas` 缩到**长边 ≤ 1200px** 并转成 JPEG，避免高糊也避免超配额；
3. 存进这台机器的 `localStorage`（键名 `portfolio.photo`），刷新后自动恢复；
4. **图片不会离开你的浏览器，没有任何上传接口**——这个站没有后端。
5. 相机原图转出来的 dataURL 若超过 3.2M 字符，会自动用更低质量重来一次；
   万一还是存不下，照片仍会显示，只是提示"刷新后需重传"，不会白忙一场。

## 4. 实现要点

**绝对路径的锚点跳转**用了 `scroll-margin-top`，所以从导航点进去不会被吸附栏盖住标题。

**滚动揭示用 `IntersectionObserver`**，元素一旦显示就 `unobserve`——
不会因为你来回滚动反复播放，也不会一直占用主线程。
没有 `IntersectionObserver` 或没 JS 时，靠 `.no-js` 类让内容直接可见，
**不会出现"JS 挂了页面一片空白"**。

**进度条和索引栏高亮**都在 `requestAnimationFrame` 里更新，滚动事件是 passive 的。

**缩略图是内联 SVG**，不是 `<img>`：没有额外请求，随主题变色，
缩放不糊，深色界面里也不会像贴上去的一块亮斑。

**无障碍**：跳转焦点环 `:focus-visible`、图标按钮有 `aria-label`、
装饰性 SVG 和符号全部 `aria-hidden`、主题开关是 `<button>` 不是 `<div>`、
标题层级连续（h1 → h2 → h3）。对比度实测见下表。

### 实测数据（本机 Chrome 无头渲染，`scripts/verify-layout.js`）

`2 个主题 × 4 个宽度 = 8 组`，全部通过：

| 检查项 | 结果 |
| --- | --- |
| 横向溢出 | 8 组全部 **0px** |
| 项目卡片栅格 | 1440/834 → 每行 2 张；390/320 → 每行 1 张 |
| 首页大标题 | 105.6 / 101.5 / 62.5 / 62.5 px，**四档都是 1 行** |
| 正文对比度（深色） | 16.37 : 1（AA 要求 4.5） |
| 辅助小字对比度（深色） | 4.77 : 1 |
| 正文对比度（浅色） | 15.52 : 1 |

## 5. 测试

```bash
npm run check        # 一条命令跑两套：API 自检 + 冒烟测试
npm run smoke        # 冒烟测试 142 项：静态 / 结构 / 脚本 / 渲染 / 头像上传 / 三新功能
npm run test:api     # API 自检 55 项：统计 / 留言 / 限速 / 蜜罐 / 隐私 / 崩溃恢复
```

两套测试都用**临时数据目录**（`DSH_PORTFOLIO_DATA`），**绝不会往你的真实统计里塞测试访问量**。

`npm run smoke` 分六组：

- **A. 静态资源**：每个文件 200 + MIME 正确，目录穿越返回 403，`POST` 返回 405，
  `/data/store.json` 与 `/data/admin-token` 一律 403
- **B. 页面结构**：锚点齐全、标题层级不跳级、页内链接都能落地、
  外链都带 `rel="noopener"`、没有遗留占位符；**每个 `data-i18n` 键中英两边都必须存在**
- **C. 样式与脚本**：花括号配平、`main.js` 能被 JS 引擎解析、令牌数量、
  断点、焦点样式齐全、没有写死的超宽容器
- **D. 真实渲染**：用本机 Chrome 跑一遍，确认卡片真的渲染出来、
  缩略图各不相同、首屏入场已完成、头像扫描已播放、年份已填；
  并核对**个人信息**（新名字在、旧名字清干净、邮箱 / 微信 / 现居 / GitHub 都对）
- **E. 头像上传**：在浏览器里**真的走一遍上传**——用 canvas 造一张 PNG 塞进
  `<input type=file>`、触发 `change`，然后断言：头像 `src` 变成 `data:image/…`、
  出现"恢复默认"按钮、照片确实写进了 `localStorage`
- **F. 多语言 · 统计 · 留言板**：在浏览器里真的点语言开关（中↔英各验一遍文案、
  `html lang`、`localStorage`）、真的提交一条留言（验列表更新、成功提示、
  限速提示、蜜罐不可见、被拒的那条没进列表）、读真实统计（PV/UV/14 根折线）

`npm run test:api` 覆盖服务端最要紧的几件事：PV/UV 去重、留言校验（空/太短/灌水/塞链接/超长）、
蜜罐丢弃、同 IP 限速且不入库、管理员令牌才能删、**`ipHash` 不出网**、
**`/data/` 无论如何读不到**、以及**`store.json` 损坏时能从 `store.jsonl` 重建**。

第 D、E、F 组需要本机有 Chrome / Edge；找不到就跳过，**受限沙箱里起不来也会明确跳过而不是假装通过**。
装 Chrome 后设一下 `CHROME_PATH` 即可：

```bash
# 布局与对比度体检（会给出"没有问题"或具体问题清单）
CHROME_PATH="C:\Program Files\Google\Chrome\Application\chrome.exe" node scripts/verify-layout.js

# 整页截图 → .screens/（本地看效果用，已 gitignore）
CHROME_PATH="..." node scripts/shots.js
```

`verify-layout.js` 守着几处容易被忽略的细节：**"上传照片"按钮必须可见且高度 ≥ 36px**
（手指点得到）、没传照片时"恢复默认"不能出现、**语言开关在当前宽度下必须真的可见**、
以及**后端可用时留言板与统计必须真的展开**（不是 hidden），留言输入框不能太矮。

URL 上还有三个开发用参数：`?reveal=all` 让所有节点直接显示（截图用），
`?theme=dark|light` 强制主题，`?lang=zh|en` 强制语言（视觉回归用）。

## 6. 服务端：数据、隐私与运维

### API

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/visit` | POST | 记一次访问（body: `{visitorId}`），返回最新统计 |
| `/api/stats` | GET | 读统计：总 PV / 今日 / 访客数 / 近 14 天 |
| `/api/guestbook` | GET | 读留言，`?offset=&limit=` 分页（最新在前） |
| `/api/guestbook` | POST | 发留言（body: `{name, text, website}`，`website` 是蜜罐） |
| `/api/guestbook` | DELETE | 删留言，需要 `Authorization: Bearer <admin-token>` |

### 数据存在哪

都在 `portfolio/data/`，**明文 JSON，方便你自己看和备份**（整个 `data/` 已 gitignore）：

| 文件 | 内容 |
| --- | --- |
| `store.json` | 访问统计 + 留言 |
| `store.jsonl` | 逐条追加的日志；`store.json` 坏了能从它重建 |
| `secret` | 哈希访客身份的随机盐（首次启动生成） |
| `admin-token` | 管理员令牌（首次启动生成） |

想换位置（比如放到数据盘）：`DSH_PORTFOLIO_DATA=/path/to/data node server.js`。

### 隐私上的取舍

- **不存原始 IP**。UV 用的是"本机随机 ID → HMAC-SHA256 取前 32 位"，盐在 `secret` 里，
  换台机器就算拿到 `store.json` 也反推不出是谁。
- **留言里存了 `ipHash`**（用于限速），但 `/api/guestbook` 的响应**永远不返回它**（有测试盯着）。
- **没有第三方统计**。不引 Google Analytics，不加追踪像素，统计数字全部来自你自己的服务端。
- **不设 cookie**。访客 ID 存在 `localStorage`，不是 cookie。

### 留言审核

有人发垃圾留言时，用启动日志里打印的那条命令删（令牌在 `data/admin-token`）：

```bash
# 启动时会打印完整命令，形如：
curl -X DELETE "http://localhost:5200/api/guestbook?id=<留言 id>" \
     -H "Authorization: Bearer <data/admin-token 里的内容>"
```

不引令牌就删不掉（401），这是有测试覆盖的。留言 `id` 可以从 `data/store.json` 里翻，
或直接在浏览器里看接口返回。

### 防滥用做了什么

蜜罐字段（机器人会填 → 静默丢弃，还假装成功）、同一地址 60 秒冷却、每天 8 条上限、
长度上限（称呼 24 字 / 留言 500 字）、控制字符清理、明显灌水判定（重复字符、
一长串乱码、三条以上链接）。**这些都是"提高门槛"，不是"防死"** ——
真被人盯上刷，还是要靠 `TRUST_PROXY=1` + 反向代理层限流。

### 部署到公网

```bash
# 1. 放在 Nginx 之类的反向代理后面，并打开代理信任（否则限速会把所有人算成一个 IP）
TRUST_PROXY=1 PORT=5200 node server.js

# 2. 记得备份 data/ 目录（就这一个目录）
```

Node 18+ 即可，没有依赖要装。`data/` 必须**可写**；
如果是只读文件系统，页面会自动把统计和留言板收起来，其余部分照常。

### 起不来的时候看什么

启动即自检：`本机自检 通过` 说明服务真的在对外应答。常见的三种情况：

| 现象 | 原因与处理 |
| --- | --- |
| `✗ 端口 5200 已经被占用` | 上一个 `node server.js` 还在跑。直接访问 http://localhost:5200/ 即可；要重启就先结束旧进程（提示里给了命令），或 `node server.js 5201` |
| 打印了启动信息、提示符随后就回来了 | 服务确实被停掉了。**这个窗口必须保持开着**，它本身就是进程；想腾出终端用 `start node server.js` 另开窗口 |
| `数据目录 … ← 不可写` | `data/` 没有写权限，统计与留言会隐藏。给目录写权限，或 `DSH_PORTFOLIO_DATA=/可写路径 node server.js` |

按 `Ctrl+C` 会打印"已停止"并以 0 退出——**退出码 0 表示是你让它停的，不是出错**。

## 7. 已知取舍

- **项目截图是自绘素材**，不是真实截图（真实截图放 `assets/shots/` 即可，代码不用改）。
  头像是真实照片，并且**网页上可以直接换成别的照片**。
- **亮底照片**（白底证件照那种）在深色页面里会变成亮斑，所以头像四边压了一层很轻的内描边
  把它收进"工作台"的框里——只压边缘，不改照片本身。
- **没有做深色/浅色两套图片**，缩略图是 SVG，靠 CSS 令牌跟着主题走。
- **头像照片存在浏览器本地**（`localStorage`），所以换台电脑就要重传一次 ——
  换来的是零后端、零上传、照片不出本机。要做成"跟着仓库走"，
  就把照片放进 `assets/` 并改 `index.html` 里那一处 `src`。
- **中英双语是"界面级"的，不是 i18n 框架**。没有复数、日期本地化之外的复杂规则；
  中文名（薛小飞）刻意不翻译。
- **留言板没有账号体系、没有审核队列**：发出来即公开，靠上面的防滥用手段 + 事后删除。
  要更严就得加"先审后发"，那就需要管理员界面了。
- **统计是"访问量"不是"分析"**：只看 PV/UV 和 14 天趋势，没有来源、页面停留、设备分布。
  要那些指标就得上专业分析工具，而这个站的原则是不引第三方。
- **`store.json` 适合个人站的量级**（几百到几万条留言）。再大应该换 SQLite，
  但那样就有依赖了。
