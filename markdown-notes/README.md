# 校样 · Markdown 笔记台

左边写 Markdown，右边实时看到版面。笔记存在浏览器本地，代码块带语法高亮。

```bash
npm start          # http://127.0.0.1:5220/
npm test           # 解析层 + 数据层，共 239 项断言
```

不需要构建、不需要装依赖：三个 JS 文件、一个 CSS、一个 `index.html`，
双击 `index.html` 也能跑（用 `npm start` 起本地服务更稳妥，剪贴板 API 对 `file://` 有额外限制）。

---

## 它是什么

一个「校样」——排版行话里，稿子是墨，印张是纸，校对者用红笔在页边做记号。
这个应用把这件事搬到了屏幕上：

```
┌──────────────┬──────────────────────────────┬──────────────────────────────┐
│  目录栏       │  稿纸（墨）                    │  印张（纸）                    │
│              │                              │                              │
│ 搜索框        │  标题                         │  ┌── 排好的版面 ──────────┐    │
│ ● 笔记一      │  创建时间 · 字数               │  │ # 标题                 │    │
│   笔记二      │  ─────────────────────       │  │ 段落、列表、表格…       │    │
│              │  H2 B I </> 代码块 链接 …      │  │ ▓ 墨色代码卡片 ▓        │    │
│              │                              │  └────────────────────────┘    │
│              │  正文（Markdown 原文）         │                        ◤ 红括号 │
│              │                              │                              │
│ 2 篇 · 2.2 KB │  已保存 08:27 │ 行 3 · 列 8   │  印张 │ 跟随光标 ●          │
└──────────────┴──────────────────────────────┴──────────────────────────────┘
```

- **左边是机器声部**：等宽字体、深墨底色，写的是一行行源码。
- **右边是纸面声部**：衬线排版、浅纸底色，看的是一页版面。
- **同一份墨**：印张里的代码卡片仍然是墨色的——稿纸的墨渗进了纸面。
- **全文只有一个强调色**（proofred `#D93F2B`），而且只用在"当前位置"这一件事上：
  页边记号、选中的笔记、焦点、危险操作。其余一律黑白灰。

## 三个真用得上的设计

**1. 页边红括号（签名交互）**
右边印张的页边有一道人手画的竖线，红括号指着你光标所在的那一块。
打字时它会跟着走，并且印张会滚动，把那一块留在视野里（"跟随光标"可以关掉）。
反过来也成立：**点印张里任意一段，左边光标跳回对应的源码行**，不用自己数行号。

行号映射是解析器给的：每个块级元素都带 `data-line` / `data-end`（1 基、含首含尾）。
嵌套列表里会选中最小（最内层）的那个块——光标在子项上，括号就不会指着一整张列表。

**2. 纸面可以编辑墨**
`- [ ]` 任务清单在印张里渲染成真的复选框，点一下会**改回左边的原文**（`[ ]` ↔ `[x]`），
顺手落盘。空格和画勾，改的都是同一份 Markdown，不是两份数据。

**3. 不停手保存**
停手 400ms 落盘一次；一直打字也不会超过 4 秒不存。
左下角始终写着状态：`待保存…` → `已保存 08:27`，存不下就直说（`仅本次会话`、`未能保存：配额已满`），
不假装成功。切走页面、关标签页都会兜底再存一次。

## 用起来是什么样

| 动作 | 怎么做 |
| --- | --- |
| 新建笔记 | `Ctrl/Cmd + N`，或目录栏右上角「＋ 新建」 |
| 搜索 | `Ctrl/Cmd + K`；同时搜标题和正文，多个词用空格隔开（都要命中），命中的词在摘要里标红 |
| 加粗 / 斜体 / 行内代码 / 链接 | `Ctrl/Cmd + B` / `I` / `E` / `K`（选中的文字会被包起来，再按一次脱掉） |
| 手动保存 | `Ctrl/Cmd + S` |
| 列表里换行 | 回车自动续 `- ` / `1. ` / `> `；空项上回车的效果是"退出这个列表" |
| 缩进 | `Tab` / `Shift + Tab`（多行选中会整块缩进） |
| 排序 | 目录栏上「最近修改 / 创建时间 / 标题」 |
| 删除 | 卡片右上角 ×，或稿纸栏右上「删除」——**删错了有 9 秒可以撤销** |
| 导出 | 「导出 .md」导出当前这篇；目录栏底部「备份」导出全部（JSON，可再「导入」回来） |
| 调整分栏 | 拖中缝；双击回对半；键盘左右方向键微调 |
| 打印 | 直接 `Ctrl + P`：只印印张，界面全部让开 |

窄屏（≤1080px）会自动变成单栏，顶部出现「笔记 / 编写 / 阅读」切换。
也可以用 `#pane=read` 这样的地址直接开在某一栏。

## 技术选择

**零依赖，手写解析器**（`js/markdown.js`，约 700 行）。
本来可以引 marked + highlight.js，但这两件事在这类工具里恰恰是最该自己掌握的：
块级元素要带行号区间（签名交互的前提），高亮要能控制 token 配色（让它服从整套配色，而不是反过来）。

支持：标题、段落、强调、删除线、行内代码、链接 / 图片 / 自动链接、
引用（含嵌套与惰性续行）、有序 / 无序 / 嵌套 / 松散列表、任务清单、
表格（含对齐）、围栏代码块（含未闭合）、分隔线、硬换行。

高亮语言：`js`/`ts`、`json`、`html`、`css`、`python`、`bash`、`sql`、`yaml`、`markdown`、`diff`，
其余语言退回通用规则（注释 / 字符串 / 数字 / 关键字）。
规则表用「每条规则自带 0 个捕获组、由构建器补一层括号」的约定，
组号即规则序号——所以能靠组号定位 token 类型，不用写一堆 if。

**安全**：笔记内容可能存在 LocalStorage 里被人手工改过，所以渲染侧自己兜底——
原文 HTML 一律转义（不做 raw HTML 透传），链接协议走白名单（`http/https/mailto/tel/#/相对路径`），
`javascript:` / `data:` 直接作废。解析层有专门的测试盯着这条线。

**可测**：解析层和数据层是纯函数，浏览器和 Node 里跑的是同一份代码。

## 已知边界

- 不支持原生 HTML 透传（安全优先，写在笔记里的 `<div>` 会原样显示成文字）；也不支持脚注、定义列表、数学公式。
- `---` 一律按分隔线处理，不认 setext 式标题（`标题\n===`）。
- 正文上限 20 万字符，超出会提示且不保存超出的部分。
- 数据只在这个浏览器的 LocalStorage 里（约 5MB）：换浏览器、清缓存都会没。
  重要内容请用「备份 / 导出 .md」留一份。
- 印张里的代码块不做折叠、不显示行号；行内 HTML 之外的实体（如 `&copy;`）原样显示。
