# 流水账 · 个人记账

> 市面上记账 App 的通病是：想让你用它的全部功能。这个只做四件事——**快速记一笔、按日期翻记录、看月度统计、数据只留在本机**。

零依赖，纯 HTML + CSS + 原生 JS，没有构建步骤，没有 npm install，没有后端，没有账号。双击 `index.html` 就能用。

## 视觉：它为什么长这样

记账这件行为的产物本来就是**一张一张的小票**。所以整页是一卷热敏纸压在深墨绿桌垫上，而不是又一个卡片式仪表盘。

| | |
| --- | --- |
| **桌垫** | `#121813` 深墨绿，带一层极淡的织纹 |
| **热敏纸** | `#f1f1ec`，无圆角——小票是切出来的，不是切圆角的 |
| **两种墨** | 墨黑 `#23282a`（收入 / 中性）+ 热敏红 `#b8322a`（支出 / 超支） |

真小票只有黑和红两个色带。这个物理约束被当成设计约束用：**没有绿色，没有渐变，没有第三种颜色**。收支靠正负号和位置区分，不靠红绿——顺带也绕开了红绿色盲的问题。

**签名元素是「分类条码」。** 统计页里每个分类是一条水平条码，长度按占比生长，纹路是真的条码纹。数据本身就是小票上那条条码——点它可以直接跳到只看这个分类的流水。

**只有一段动效：出纸。** 提交时一条热敏打印头扫过新行，把它「印」出来，纸往下走一格。除此之外没有动画——记账工具不需要表演。

撕口是小票底边那道锯齿，用 SVG mask 做的，固定在出纸口位置。

## 运行

```bash
cd ledger
node server.js          # 默认 http://localhost:5190/
```

也可以直接双击 `index.html`。区别只有一个：PWA 的 Service Worker 和「装到主屏」要求安全来源，`http://localhost` 满足，`file://` 不满足。`file://` 下记账、统计、导入导出全部照常工作，只是装不了离线应用。

## 核心需求怎么落的

### 1. 快速添加收支记录

- 打开页面光标已经在金额框里，输完按回车就记下了 —— **全程不用碰鼠标**，两秒一笔
- 触屏有数字键盘（`00` / `+` / `−` / `⏎`），可收起，选择会记住
- **金额栏支持算式**：`128+36.5` 直接算成 164.5。AA 分账时不用先算再输
- 分类点一下就切；上一次用过的分类会记住，下次默认选中
- 记错了不用去列表里翻——右下角提示条带**撤销**，几秒内一键回退
- 快捷键：<kbd>N</kbd> 回到金额框，<kbd>/</kbd> 跳到搜索，<kbd>Alt</kbd>+<kbd>←/→</kbd> 翻月，<kbd>Esc</kbd> 取消修改 / 清筛选

### 2. 按日期查看记录

右侧「流水」页按日期分组，每天一个抬头，带星期、当天支出收入小计。支持：

- **搜索**备注、分类名、金额数字、日期
- **分类**筛选、「支出/收入」切换
- **金额区间**筛选
- 月份前后翻，或点月份标题直接选；「本月」一键回来；「全部」按月份分段展示全部历史

### 3. 查看月度统计

「统计」页四块，按「先看该不该省，再看省在哪儿」排序：

1. **预算** —— 进度条 + 还剩多少、剩下的日子每天能花多少
2. **分类条码** —— 支出/收入切换，点任一条跳去看它的流水
3. **每日支出** —— 当月每天一根柱，虚线是日均；今天那根是红的
4. **近 6 个月** —— 收支双柱对比

「流水」页顶部还有三格汇总：支出、收入、结余，各带与上月的环比涨跌。

### 4. 数据本地存储

写在浏览器 `localStorage`，键名 `ledger.v1`。不上传，不联网，没有账号，没有服务端。

**唯一的风险你要知道**：清浏览器数据、换设备、换浏览器 = 账本没了。所以设置页里放了导出。**建议每月导出一次 JSON 存网盘。**

## 扩展功能

| 功能 | 说明 |
| --- | --- |
| **分类标签** | 内置 10 个支出分类 + 7 个收入分类，可以改名、删除、新增 |
| **导出 / 导入** | 导出 JSON（完整备份，含分类与预算）和 CSV（Excel / Numbers / WPS 都能开，带 BOM 不乱码）。导入自动识别 JSON 或 CSV，**按「日期+时间+类型+金额+分类+备注」去重**，重复的跳过，不会灌出双份 |
| **预算与超支** | 月度总预算 + 分类预算。用到 80% 起，小票底部开始印红字警告；某笔正好把预算打破时会当场提示 |
| **搜索与筛选** | 见上 |
| **PWA 离线** | Service Worker 缓存应用外壳，断网能打开也能记账（数据本来就在本地）。浏览器支持时顶栏会出现「装到主屏」，设置页里也有一个 |

导入时 CSV 表头可以任意顺序、任意缺列，会按名字猜：

```csv
日期,时间,类型,分类,金额,备注
2026-02-14,12:30,支出,餐饮,28.50,和同事吃饭
2026-02-10,,收入,工资,12000,
```

没写类型的，靠金额的正负号判断；分类在这个账本里不存在的，会自动建一个；同一分类名在支出和收入下是两个不同分类。

## 连续记账

小票底部有一行 **连续记账 N 天**。今天还没记的时候，从昨天起算 —— 白天不会平白无故断掉，晚上补记也算数。

这是这个应用唯一一点「游戏化」，因为需求里说的是**养成记账习惯**，而不是管住钱。

## 其他

- 同时开多个标签页不会互相覆盖：一边记完，另一边靠 `storage` 事件自动同步并提示。所有改动都是当场落盘的，**不放在 `beforeunload` 里做**——那样写的是内存里的旧快照，会把另一个标签页刚存的数据冲掉
- 窄屏（≤1000px）自动变成单列：纸卷在上，账页在下，月份栏吸顶
- 键盘可达：所有操作可 Tab 到、有可见焦点环、页签遵循 tablist 键盘规范、提示条是 `aria-live`
- 尊重 `prefers-reduced-motion`：关掉动画，条码直接显示到位
- `Ctrl+P` 打印时只留小票，账页自动隐藏——想留个纸面记录可以直接印出来
- 存不进本地存储时（无痕模式 / 空间满）会明确报错，而不是静默丢数据

## 测试

两套测试都是**零依赖**的，不用装任何东西。

### 数据层：`scripts/unit-test.js`

```bash
node scripts/unit-test.js      # 136 项断言
```

给 `store.js` 喂一个最小的 `window` / `localStorage`，然后在 Node 里跑。覆盖金额算式解析、脏数据清洗、增删改查、排序、统计口径、连续天数、预算、分类改挂、CSV / JSON 往返一致性，以及存储写失败时能不能察觉。

### 整页：`scripts/smoke.html`

```bash
node server.js
# 浏览器打开 http://localhost:5190/scripts/smoke.html
```

它在一个 iframe 里加载**真实的 index.html**，然后在真实 DOM 上点：填金额、按回车、切页签、点条码、拉筛选、设预算、改名删分类、导入导出……103 项断言全部打在页面上。不 mock，跑的就是线上那份代码。

> 它会先清空 `localStorage` 里的账本。别拿正在用的浏览器打开。

开发这套东西时抓到的两个真问题，都留了回归断言：

- **CSV 导入放行了 0 元行**。`normalize()` 会拦住 0 元记录，但 CSV 导入路径绕过了它——导出再导入就能灌进一堆 0 元条目。
- **多标签页会丢数据**。`beforeunload` 里的一次落盘写的是内存里的旧快照；A 页开着的时候 B 页记的账，被 A 页刷新前那一下覆盖没了。现在改成改动即落盘 + `storage` 事件同步。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构：纸卷 / 账页 / 提示条 / 确认框 |
| `styles.css` | 视觉：桌垫、热敏纸、撕口、条码、打印头动效 |
| `store.js` | 数据层：存取、增删改查、统计计算、CSV / JSON 读写、金额算式解析 |
| `app.js` | 交互层：录入、流水、统计、设置、快捷键、PWA |
| `sw.js` | Service Worker：应用外壳缓存、离线、后台更新 |
| `manifest.webmanifest` | PWA 清单，含「记一笔」「看统计」两个快捷方式 |
| `server.js` | 零依赖本地静态服务器（PWA 需要安全来源） |
| `icons/icon.svg` | 图标源文件（小票 + 撕口 + 条码） |
| `scripts/make-icons.js` | 图标生成脚本（手写 PNG，零依赖） |
| `scripts/unit-test.js` | 数据层测试，`node` 直接跑 |
| `scripts/smoke.html` | 整页冒烟测试，浏览器直接开 |

图标是脚本生成的 —— 一个图标包几十兆，这里用 Node 内置 zlib 手写 PNG，4×4 超采样去锯齿，总共 9 KB：

```bash
node scripts/make-icons.js
```

改动 `icons/icon.svg` 里的设计后跑一次，`icons/*.png` 会重新生成。`icon-maskable-512.png` 是同一张图缩进 74% 安全区，被系统裁成圆形也不掉内容。

## 已知边界

- 单账本、单用户，没有多账本 / 多币种
- `localStorage` 一般上限 5 MB，按一条记录约 150 字节算，够记十几年；真到上限会报错提示你导出
- 日期不校验未来时间——你可以记一笔明年的账，这个应用不拦你
