# 水尺 · 自动提醒喝水的网站

一根带刻度的量水尺。左边固定在视口里的刻度柱同时有**两套刻度**：左侧是毫升刻线，右侧是「计划时刻」标记——把"几点该喝到多少"画在同一根尺上；水面之上的斜线缺口就是你现在欠的水量。右边的读数、记录和设置可以滚动。

零依赖，纯 HTML + CSS + 原生 JS，不需要构建。

## 运行

```bash
cd water-reminder
node server.js          # 默认 http://localhost:5180/
```

也可以直接双击 `index.html`。区别：桌面通知需要安全来源，`http://localhost` 满足条件；`file://` 打开时部分浏览器会拒绝通知权限，页面横幅、提示音和标题提醒照常工作。

## 它怎么提醒你

| 通道 | 说明 |
| --- | --- |
| 页面横幅 | 右下角弹出「该喝水了」，带"记一杯"和"推迟 10 分钟" |
| 桌面通知 | 首次记录时会请求一次权限，之后到点推送系统通知 |
| 提示音 | Web Audio 合成两声柔和音（E5 → B5），不是警报声。浏览器要求先有一次交互，因此第一次点击页面后才会出声 |
| 标签标题 | 标题变成 `该喝水了 · 水尺`，切到别的标签页也能看到；平时显示今日已喝毫升数 |

提醒时间是**从上一次喝水算起**的间隔，而不是固定时刻。默认：作息 08:00–22:00，每 45 分钟提醒一次，每日目标 2000 ml。作息时段之外不提醒；超过作息结束时间就顺延到第二天。夜里/午休想停就点「暂停提醒」。

## 记录方式

- 三个预设按钮：小杯 150 / 玻璃杯 250 / 水壶 500 ml
- 「其他容量」输入任意数值（10–2000 ml）
- **直接拖动刻度柱上的水位**，松手即按差值记录。水位只能往上加；要减少请在记录里点「删除」——本期水量由记录列表决定，不会因为误拖而丢数据。

## 其他

- 数据存在浏览器 `localStorage`（键名 `water-gauge.v1`），保留最近 60 天，不上传任何服务器。
- 「最近 7 天」展示每日完成度，虚线是目标线。
- 窄屏（< 900px）时刻度柱会横过来放在顶部，拖拽方向随之变成左右。
- 已处理键盘焦点样式、`prefers-reduced-motion`、空状态与错误提示（含通知被浏览器禁止时的说明）。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构：刻度柱 / 读数 / 记录 / 7 天 / 设置 / 提醒横幅 |
| `styles.css` | 视觉：仪表灰纸、双刻度、倾角缺口、横竖两种刻度状态 |
| `app.js` | 调度与提醒、通知与音效、本地存储、拖拽记录、渲染 |
| `server.js` | 零依赖本地静态服务器 |
